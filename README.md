# sing-box Presets

Набор инструментов и пресетов для автоматической генерации правил маршрутизации (IP-фильтров) в формате [sing-box](https://github.com/SagerNet/sing-box).

Проект позволяет объединять списки CIDR из различных источников (Google, Cloudflare, Telegram и др.), вычитать из них исключения (локальные диапазоны, приватные сети) и сохранять результат в форматах `.json` (rule-set) или `.srs` (binary rule-set).

## Структура проекта

- `cmd/gen/` — генератор правил на Go.
- `include/` — исходные списки IP-диапазонов (TXT, JSON).
- `exclude/` — диапазоны для исключения (RU-сегмент, приватные сети).
- `presets/` — конфигурационные файлы для сборки наборов (содержат пути к файлам из `include`).
- `example_files/` — примеры конфигураций `config.json` и `docker-compose.yml` для использования сгенерированных правил в `sing-box`.
- `output/` — сгенерированные JSON rule-sets.
- `rulesets/` — сгенерированные бинарные `.srs` файлы.

## Использование

### Требования
- Go 1.24+
- Установленный `sing-box` (для компиляции в `.srs`)

### Сборка и запуск
1. Соберите генератор:
   ```bash
   go build -o gen ./cmd/gen/main.go
   ```

2. Запустите генерацию:
   ```bash
   ./gen
   ```
   Программа прочитает файлы из `presets/`, применит исключения из `exclude/` и сформирует файлы в `output/` и `rulesets/`.

## Как это работает
Генератор выполняет следующие шаги:
1. Загружает CIDR из всех файлов, указанных в пресете.
2. Объединяет перекрывающиеся диапазоны.
3. Вычитает из полученного списка все диапазоны, указанные в файлах исключений (`exclude/`).
4. Формирует JSON rule-set, совместимый с sing-box.
5. Автоматически компилирует JSON в бинарный формат `.srs` с помощью утилиты `sing-box`.
